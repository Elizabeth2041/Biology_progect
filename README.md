# Дерево родства животных

Школьный проект по биологии: сайт о кладах - современном способе классифицировать живое по родству.

Простое описание проекта по шагам: [ОПИСАНИЕ_ПРОЕКТА.md](ОПИСАНИЕ_ПРОЕКТА.md).

## Как открыть сайт

Откройте файл `index.html` в браузере двойным щелчком. Интернет и сервер не нужны.

Чтобы выложить сайт в интернет, подойдёт GitHub Pages: в настройках репозитория включите Pages для ветки `main`.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Страница сайта и все объясняющие тексты |
| `css/style.css` | Оформление |
| `js/app.js` | Дерево, фильтр по годам, сервис «Общий предок» |
| `data/tree-data.js` | Готовые данные. Создаётся скриптом, вручную не редактируется |
| `img/` | Картинки видов, получены через API OneZoom |
| `tools/species.tsv` | Список животных: латинское и русское название |
| `tools/clades.tsv` | Словарь клад: русские названия, ранги, пояснения |
| `tools/extra_clades.tsv` | Общепринятые клады, у которых в базе нет своего названия |
| `tools/notes.tsv` | Примечания «учёные ещё спорят» |
| `tools/build_data.py` | Скрипт, который собирает данные |
| `tools/otol.py` | Запросы к Open Tree of Life и OneZoom с кэшем |

## Как изменить состав дерева

1. Добавьте или уберите строку в `tools/species.tsv`. Латинское название должно находиться в [Open Tree of Life](https://tree.opentreeoflife.org/).
2. Если нужна новая клада с русским названием, добавьте её в `tools/clades.tsv`.
3. Запустите сборку (нужны Python 3 и интернет):

   ```
   python3 tools/build_data.py --print
   ```

   Ключ `--print` выводит получившееся дерево текстом. Просмотрите его: новый вид должен оказаться рядом со своими родственниками.
4. Обновите страницу в браузере.

Ответы серверов сохраняются в `tools/cache/`. Чтобы получить свежую версию дерева из базы, удалите эту папку и запустите сборку заново.

## Как устроены данные

- Порядок ветвей взят из синтетического дерева Open Tree of Life без изменений. Скрипт только убирает промежуточные узлы: остаются точки ветвления наших видов и клады из словаря.
- Если точка ветвления не имеет названия, но лежит внутри названной клады, в которой нет других наших видов, она подписана именем этой клады. В данных это `naming: "within"`.
- Год клады - год самой свежей работы из поля `supported_by` в Open Tree of Life. Работы из поля `partial_path_of` показаны отдельно как косвенные подтверждения и в фильтре не участвуют.
- Счётчики конфликтов из Open Tree of Life не используются: они относятся к полному дереву с миллионами видов, а не к нашей выборке.

## Источники

- Open Tree of Life, синтетическое дерево opentree16.1. Hinchliff C. E. et al. (2015). Synthesis of phylogeny and taxonomy into a comprehensive tree of life. *PNAS* 112: 12764–12769.
- OneZoom Tree of Life Explorer, API изображений. Wong Y., Rosindell J. (2021). Dynamic visualisation of million-tip trees: the OneZoom project. *Methods in Ecology and Evolution*.
- Викиданные - сверка русских названий.

Авторы и лицензии изображений указаны на сайте в карточке каждого вида и в файле `data/tree-data.js`.
